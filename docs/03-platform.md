### 远程登录与网络连接

1. **物理连接**：使用标准 RJ45 网线连接机身背部调试网口与外部开发笔记本电脑。之所以采用有线直连，是因为比赛场馆无线信道极度拥挤且存在同频干扰，迫使底层固件调试、程序分发与系统维护必须依托高抗扰的物理双绞线。
2. **IP 地址配置**：
   - 调试笔记本有线网卡配置为静态 IP：`192.168.12.11`（子网掩码 `255.255.255.0`）。
   - 机器人调试网口出厂固定 IP 为：`192.168.12.100`。
3. **远程登录凭证**：
   - 支持通过 SSH 终端访问（`ssh cxzk@192.168.12.100`）或 NoMachine 远程桌面图形化访问。
   - 登录用户名：`cxzk`
   - 登录密码：`cx125`
   - 登录后严禁随意升级底层系统内核或改动电机硬件驱动，避免破坏机载运行环境的稳定性。

### 开机与遥控手柄操作

1. **开机流程与初始状态**：
   - 开机前首先检查背部红色急停开关处于顺时针旋转松开弹起状态；核验动力电池上、下两处机械锁舌完全卡入锁槽，防止机体走动时电池脱落造成瞬时断电。
   - 按下机身背部中间电源开关，等待机载工控机与伺服板卡完成自检，启动耗时约为 30 至 60 秒。
   - 启动完毕后，系统处于初始准备状态，此时全身关节呈现零阻力特性，可以用手自由拨动关节摆出指定初始姿势。必须在保护吊架拉紧状态下进行此操作，防止机体由于关节无力矩支撑就地软瘫坠地。
2. **手柄组合键定义（罗技无线手柄）**：
   - **准备就绪（Ready）**：同时按下 `左1`（LB） + `执行按键 A`，下肢各个关节电机开始受电，缓慢旋转至标准直立零位姿态。
   - **开始运行模型**：同时按下 `左1`（LB） + `执行按键 B`，开始执行当前加载的行走或踢球运动模型。
   - **紧急切换阻尼**：同时按下 `左1` + `右1` + `执行按键 Y`，机器人各个关节瞬间切入阻尼耗能状态，迅速吸收残余动能并平稳停止。
   - **阻尼后复位**：同时按下 `左1` + `右1` + `执行按键 X`，等待 3 秒后系统恢复初始零阻力状态。
   - **移动控制（行走模型激活状态下）**：摇杆回中时机体保持原地踏步或踏步直立；左拨杆负责推拉控制机体前后左右平移速度，右拨杆左右拨动负责控制机体转向角速度。
   - **手柄休眠唤醒**：手柄在停止操作一段时间后会自动切入低功耗休眠，点按一次 `左1` 或 `右1` 按键即可重新建立无线配对。

## 3.2 关节与自由度

双足人形机器人的单腿通常配置 6 个主动自由度：髋关节 3 个（前后俯仰摆动、侧向摆动与轴向旋转）、膝关节 1 个（前后俯仰折叠）、踝关节 2 个（前后俯仰与侧向滚转）。这 12 个下肢自由度构成了闭环运动控制的物理执行器。

| 关节部位 | 自由度数量 | 运动学职责 | 异常或损坏时的系统级链条反应 |
| :--- | :--- | :--- | :--- |
| **髋（前后俯仰）** | 1 | 驱动大腿前后摆动，直接决定行走步幅大小 | 步幅严重受限，迈腿无法克服机体惯性，迫使步态频率被迫降低 |
| **髋（侧向摆动）** | 1 | 控制骨盆在冠状面内的左右横移与重心转移 | 无法在单腿支撑相将重力投影有效转移至支撑足底，导致机体向摆动侧严重侧倾摔倒 |
| **髋（轴向旋转）** | 1 | 驱动整条腿绕垂直轴旋转，实现原地转向与侧向切球 | 机体航向无法调节，机器人在追球时无法收拢切向角，导致踢球轨迹严重偏离目标球门 |
| **膝（前后俯仰）** | 1 | 调节腿部有效杆长，提供支撑缓冲与屈膝发力 | 腿长无法主动收缩，摆动相脚掌极易绊挂草皮；同时无法完成下蹲蓄力，导致跌倒后自主起身动作彻底失效 |
| **踝（前后俯仰）** | 1 | 控制足底前后触地倾角，在双脚触地时调节重心前后位移 | 无法吸收脚跟触地瞬间的高频撞击载荷，导致步态能量发散，机体极易向前扑倒 |
| **踝（侧向滚转）** | 1 | 贴合不平整草皮表面，抵御侧向对抗碰撞 | 侧向抗扰动能力完全丧失，受到对手轻微推挤便会使重心迅速脱出支撑多边形，由此导致整机翻倒 |

> [!NOTE]
> 关节绝对零位由高精度光电编码器读数与机械标定销位共同确定。一旦经历猛烈冲撞跌落、更换伺服减速器或发现零位漂移，必须依照厂家标定治具重新写入绝对零位偏置，否则运动学正反解算将全盘失准。

## 3.3 IMU 与姿态估计

机载 IMU（惯性测量单元）是维持双足机器人动态平衡的神经中枢，持续输出高频运动学物理量：

- **三轴角速度**：测量机体在三维空间中旋转的动态角速率，用于快速检测失衡翻转趋势。
- **三轴加速度**：测量重力加速度在机体坐标系下的分量以及外力碰撞产生的瞬态冲击。
- **解算姿态角**：芯片内部硬件互补滤波解算得出的横滚角（Roll）、俯仰角（Pitch）与偏航角（Yaw）。

在运控系统中，IMU 数据直接参与平衡控制器的反馈回路。当横滚角或俯仰角超出动态稳定包络（如机体倾斜超过 35 度）时，安全保护逻辑将立即切断行走模型并触发阻尼或倒地保护动作。

| 误差来源 | 物理成因与表现特征 | 缓解与消除措施 |
| :--- | :--- | :--- |
| **零点漂移（Bias）** | 陀螺仪在静止状态下输出非零角速度，经时域积分后导致姿态角发散 | 系统上电后必须保持静止采样 3 至 5 秒，计算角速度静态均值作为静态偏置并在后续解算中扣除 |
| **温度漂移** | 传感器芯片内部温度上升导致零偏数值发生非线性漂移 | 在机体充分预热达到热平衡后执行校准，或建立多项式温度补偿查找表实时校正 |
| **足底冲击振动** | 双足高速踩踏地面产生剧烈的高频冲击波，加速度波形充满高频尖峰噪点 | 在控制算法前级部署数字低通滤波器（如二阶巴特沃斯滤波），滤除冲击频段 |
| **机械安装偏角** | IMU 芯片引脚轴向与机体真实几何坐标轴存在微小装配夹角 | 严格测量物理装配外参，在软件驱动层引入固定旋转矩阵执行坐标基底旋转补偿 |

## 3.4 足式里程计与误差累积机理

人形机器人缺少轮式车辆连续滚动的物理车轮，其位移推算完全依赖非连续足底接触的正运动学推导：通过足底触地开关检测支撑相，利用关节编码器读数正向推算支撑足底相对机体质心的位置，再假设足底与地面无相对滑动，逆向推导出机体相对地面的位移增量。

足式里程计之所以必然产生累积漂移，归因于以下客观物理制约：

| 误差来源 | 物理成因 | 对系统的实际影响与处理方法 |
| :--- | :--- | :--- |
| **足底草皮打滑** | 人工草皮纤维在切向剪切力下发生倒伏，足底与草皮发生相对滑动 | 里程计推算位移显著大于实际物理位移，迫使系统必须依靠视觉标线观测提供绝对位置锚点进行校正 |
| **橡胶脚垫弹性形变** | 足底缓冲橡胶在数十公斤机体承重下产生非线性压缩与形变恢复 | 接触点空间坐标产生数毫米的动态浮动，由此导致正运动学解算出现微小高频抖动 |
| **关节机械微小间隙** | 减速器齿轮侧隙与连杆螺栓微小旷量在高负荷冲击下被逐级放大 | 长距离行进后直线轨迹向某一侧逐渐偏斜，必须定期紧固螺栓并标定机械零位 |
| **时钟时间戳抖动** | 视觉图像曝光时间戳与关节电机反馈时间戳存在非确定性传输延迟 | 姿态补偿矩阵与图像发生时序错位，导致投影到地面上的目标坐标发生晃动 |

足式里程计能够提供高采样率、低延迟的短时运动增量，但无法独立消除长期漂移；相机视觉观测采样率较低且存在几何对称混淆，但具备绝对位置无累积误差的特性。两者的深度融合是实现稳定定位的前提。

## 3.5 机载软件结构与运行频率

机载软件由多个跨进程节点协同构成。不同层级的模块具有截然不同的控制带宽要求，必须分配合适的调度频率：

| 功能模块 | 运行频率 | 核心输入数据 | 输出产物与工程约束 |
| :--- | :--- | :--- | :--- |
| **运动控制（Motion）** | 100–500 Hz | 期望机体速度、IMU 高频姿态反馈、关节编码器角度 | 输出各关节电机的目标力矩与位置指令。之所以要求百赫兹以上，是因为机体倒立摆倒伏时间常数极短，必须在毫秒级内输出抗扰力矩 |
| **相机驱动（Camera）** | 30–60 Hz | 传感器原始光电信号 | 输出标准 RGB 彩色图像与空间校准深度流，受限于感光元件曝光时间与 USB 传输带宽 |
| **视觉推理（Perception）** | 15–30 Hz | 原始图像帧 | 输出球体、球门立柱与场地标线的像素边界框与类别置信度，受机载工控机算力严格制约 |
| **定位系统（Localization）**| 10–30 Hz | 视觉几何特征、足式里程计增量 | 输出机体在场地绝对坐标系下的位置坐标与朝向角 |
| **战术决策（Behavior）** | 5–20 Hz | 机体全局位姿、球体空间位置、裁判盒比赛状态 | 输出机器人战术意图与期望底盘速度，无需过高频率，避免策略在临界状态下发生高频震荡 |

## 3.6 电气系统与通信接口

电源配电架构与物理总线是机器人运行的物质基础。任何电气接线疏忽都会直接导致控制器芯片击穿或电池永久报废。

| 电气子系统 | 功能职责 | 操作注意事项与风险控制 |
| :--- | :--- | :--- |
| **高压动力母线** | 直接连接动力电池，为全身伺服电机提供大电流供电回路 | 严禁带电拔插高压动力插头；插头公母端一旦接反将瞬间击穿所有电机的逆变 MOS 管 |
| **低压逻辑电源** | 为机载工控机、传感器与控制主板提供隔离纯净稳压电源 | 必须与动力母线在物理上进行光电隔离与独立走线，防止电机急加速时产生的大幅反电动势浪涌击穿工控机主板 |
| **CAN / EtherCAT 现场总线**| 负责工控机与关节伺服驱动器之间高频实时传输控制指令 | 总线两端必须正确配置 120 欧姆终端匹配电阻，避免高频电磁波反射引发丢包卡死 |
| **千兆以太网链路** | 负责相机大流量数据传输、调试机远程访问以及裁判盒广播接收 | 调试时检查网线水晶头机械卡扣完好，杜绝因线缆松动导致通信中断 |
| **硬件物理急停回路** | 通过大功率继电器或空气开关物理硬切断高压动力供电 | 独立于所有操作系统与控制软件，即使机载系统彻底死机，硬件急停仍必须可靠切断动力 |

### 上电与接线操作规程

1. **坚持固定的上电顺序**：必须先开启低压逻辑电源，等待工控机系统加载完毕、通信总线初始化成功后，再闭合高压动力电源。反向操作会在逻辑控制引脚未建立稳定参考电平的情况下突然施加高压，极易导致伺服驱动器瞬态逻辑错乱。
2. **严防动力锂电池过放**：锂电池单体电压绝对禁止跌破安全截止阈值。一旦机载报警蜂鸣器响起或电压低于设定红线，必须立即下电充电；长期闲置的电池应维持在半电荷储存状态。
3. **急停按钮的物理后果认知**：必须深刻认识到急停按钮是硬件切断动力，切断后机器人将瞬间失去任何支撑力矩并直接按自由落体撞地砸损。常规测试出现失控苗头时，应当优先使用遥控器按下组合键切入阻尼状态，仅在遭遇线路冒烟、明火或人员安全受到威胁时才允许拍下急停。
4. **更换器件后的绝缘核验**：在更换电机、传感器或重新走线后，必须先用万用表排查电源对地是否短路，确认信号线无错位后方可接入电池上电。
