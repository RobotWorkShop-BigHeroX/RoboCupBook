# 5 安全守则

> **实验室铁律 · 生命至上**  
> 参赛的人形机器人全身采用航空级铝合金与碳纤维结构，净重达数十公斤。内部高扭矩无刷电机配合高减速比行星/谐波减速器，瞬时爆发力极其惊人。在调试与测试过程中，**任何微小的程序 Bug 或参数越界都有可能引发剧烈甩动甚至致伤**。所有队员必须将以下安全守则深深刻入肌肉记忆！

---

## 5.1 吊机悬挂与保护规范

```
               ┌────────────────────────┐
               │    实验室移动吊机横梁   │
               └───────────┬────────────┘
                           │ 承重安全钢丝/吊绳 (留有 5~10cm 余量)
                     ┌─────┴─────┐
                     │ 登山级挂扣 │
                     └─────┬─────┘
                           ▼
                  ┌──────────────────┐
                  │ 机器人躯干吊装环 │
                  │ (重心上方牢固受力)│
                  └──────────────────┘
```

1. **必须挂吊机**：凡是在实体机器人上进行行走、步态调参、起跳或踢球测试，**机器人必须全程牢固挂在安全吊机绳索下方**。
2. **吊绳高度调节**：吊绳垂直长度应调节至使机器人双足刚刚贴紧草皮，保留 5~10 cm 的自然下沉余量。一旦机器人失去平衡，吊绳能够瞬间受力将其悬吊在半空，彻底杜绝砸地损毁机件或飞扑伤人的风险。
3. **禁止双脚悬空空转**：在机器人处于行走控制算法使能状态下，**严禁在关节没有处于刚性自锁的情况下直接将机器人双脚悬空**！缺乏地面反作用力支撑会导致闭环足底压力反馈与步态状态机发散，引发关节电机超速暴转甚至烧毁驱动板。

## 5.2 严谨的“三人协作测试制”

在实验室进行任何真机动力学测试时，**严禁单人私自上电运转**！必须遵循标准的三人协作 SOP 机制：

| 岗位职责 | 人员代号 | 核心任务与安全动作 |
| :--- | :---: | :--- |
| **吊车领航员** | **人员 A** | 双手紧握吊车扶手，视线紧盯机器人重心，伴随机器人行进平滑推移吊车，随时做好向上拉拽防跌准备。 |
| **遥控主控手** | **人员 B** | 手持无线安全遥控器，拇指时刻搭在“一键切阻尼”按键上，高度专注，情况不对立刻按压。 |
| **急停与地面监护员** | **人员 C** | 站在动力电缆与急停按钮（E-Stop）旁，监控测试区域闲杂人员，负责记录异常报错日志，必要时果断拍下急停。 |

## 5.3 紧急处置与“进阻尼”肌肉记忆

> [!CAUTION]
> **如果机器人出现危险动作（如全身剧烈抖动、高频自激震颤、关节大幅扭动），不要犹豫，立马进阻尼！**

### 1. 为什么“进阻尼”优于“直接切急停”？
- **阻尼模式（Damping Mode）**：将各电机相线短接或施加低阻尼电流，使所有关节瞬间失去主动驱动力矩，变为柔顺的液压阻尼手感，机器人会在吊机保护下自然下垂，保护齿轮箱不崩齿。
- **Stop 按钮（急停硬断电）**：直接切断动力母线。在机器人高速甩腿的瞬间如果硬断电，巨大惯性可能对减速器齿根产生严重机械冲击。
- **操作准则**：练就第一肌肉记忆——**“情况不对，先切阻尼”**；如果阻尼失效或通信中断，**果断拍下 Stop 按钮**！

## 5.4 机器人开机与复位规范

1. **上电前关节手动复位**：
   在接通动力电池或高压母线前，必须先在完全断电状态下，由人工协助将机器人的髋、膝、踝、臂各关节摆正到**标定初始零位（Zero Calibration Pose）**。
2. **严禁带载开机**：
   严禁在关节扭曲、处于机械死点或足底踩在障碍物上的状态下直接开启总线控制。突然施加的初始目标力矩可能导致瞬间冲撞损坏连杆。
3. **低压与高压分离上电**：
   先开机载工控机与低压逻辑电（确认通信正常、传感器读数稳定），在确认无报错提示后，发出警示口令：*“注意，准备上高压！”*，再闭合主接触器进入动力测试。
