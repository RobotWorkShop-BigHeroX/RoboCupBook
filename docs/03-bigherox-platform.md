## 2.1 T4型号机器人的介绍

当前队伍主要基于**中联重科（Zvalley）T4 型号小人形机器人**开展研发与赛事验证（待后续新版硬件交付后将无缝升级更新至新构型）。

### 2.1.1 机器人核心硬件与结构概览
- **机身规格**：
  - 身高约 60~75 cm 级别，全机身采用高强度铝合金及碳纤维复合材料骨架。
  - 具备高功率密度无刷伺服关节，拥有充足的关节峰值扭矩以应对高速踢球与动态跨步冲击。
- **计算核心**：机载高算力嵌入式工控机（如 NVIDIA Jetson 系列），集成 GPU 加速核心以支撑端侧 YOLO 目标检测模型与运动控制状态机实时计算。
- **电源系统**：高倍率锂聚合物动力电池组，配备独立低压主板供电与高压母线动力回路断路隔离。

### 2.1.2 关键传感器与器件深度剖析

#### 1. IMU（惯性测量单元）
- **提供数据**：
  - **3 轴角速度** ($\omega_x, \omega_y, \omega_z$)：以高达 200~1000 Hz 的频率监测躯干旋转速率。
  - **3 轴线性加速度** ($a_x, a_y, a_z$)：用于重力方向感知与突发碰撞检测。
  - **姿态四元数 / 欧拉角**（Roll 横滚, Pitch 俯仰, Yaw 偏航）：通过内置扩展卡尔曼滤波（EKF）融合解算机体绝对姿态。
- **实际应用用途**：
  - **动平衡闭环**：在机器人单腿支撑相位，利用 Pitch 和 Roll 角偏差计算躯干姿态倾角，动态调整支撑腿踝关节与髋关节的目标补偿角，维持零力矩点（ZMP）稳定在足底多边形内部。
  - **跌倒检测与姿态恢复**：当 Pitch 或 Roll 倾角超过设定阈值（例如 $\pm 45^\circ$ 且角速度异常时），触发紧急跌倒保护状态，提前锁死柔顺或进入缓冲姿态；倒地后判定当前为俯卧或仰卧，自动调用对应的起身（Get-up）动作轨迹。
- **数据读取机制**：在 ROS 2 中通过统一标准话题订阅（通常为 `sensor_msgs/msg/Imu`）。

#### 2. 里程计（Odometry）
- **实现原理**：
  - 人形机器人不同于轮式底盘，通常依赖**足端运动学与支撑相检测**。当判定左脚牢固着地（支撑相）时，利用正运动学（Forward Kinematics, FK）根据髋、膝、踝关节各编码器的实际读数，积分计算躯干相对于支撑足的相对平移与旋转。
- **局限与融合**：
  - 足式里程计在长时间行走、草皮打滑或碰撞时会产生严重的**累积漂移（Drift）**。
  - 因此，里程计位姿只能作为局部位姿估计输入，必须与视觉感知的场地标线（白线交点、角球点、中圈）通过**粒子滤波（Monte Carlo Localization）**或 EKF 进行全局绝对校正。

## 2.2 网站平台的介绍

队伍内部开发了专用的战队参赛与赛事资产管理系统，涵盖：
1. **比赛战报与多媒体归档**：集中管理历年比赛录像、裁判盒数据包记录（GC Log）及队伍技术问答。
2. **知识沉淀与文档平台**：内部架构讲解 PPT 及新人快速培训讲义（相关未脱密 PPT 同样存放于私有子模块中）。
3. **软硬件资产台账**：跟踪每台机器人的舵机寿命、工控机编号及电池充放电健康度。

## 2.3 中联重科 Zvalley 的资源

中联重科为仿生人形机器人提供了完善的软硬件开源生态体系，研发队员日常开发需熟练查阅以下官方站点：

1. **中联重科开放资料总站**：[https://eai.zvalley.com/openSource](https://eai.zvalley.com/openSource)  
   汇集了 Zvalley 旗下的最新固件、开发板文档与工具链更新。
2. **中联重科 SDK 说明网站**：[SDK 文档中心](https://eai.zvalley.com/openSource/detail/2087512650565427200)  
   详解低层电机通信协议、EtherCAT/CAN 总线读写 API 及传感器底层驱动接口。
3. **中联重科 SDK-GitHub 网站**：[http://github.com/Zvalley-Robotics/zv_robot_sdk](http://github.com/Zvalley-Robotics/zv_robot_sdk)  
   提供 C++ / Python 的官方 SDK 源码，包含完整的示例代码与编译配置文件。
4. **Z01 机器人仿真资产网站**：[Z01 仿真模型下载](https://eai.zvalley.com/openSource/detail/2109932634205204480)  
   提供 URDF、MJCF（MuJoCo）与 USD（Isaac Sim）标准刚体惯量、碰撞体积和网格资产，是进行仿真测试的必备模型包。
5. **Zlab_Gym 开发手册**：[Zlab_Gym 指南](https://eai.zvalley.com/openSource/detail/2109922358609195008)  
   指导如何利用强化学习框架（Isaac Gym / OmniGibson）进行人形步态与运动控制策略的大规模端到端训练。
