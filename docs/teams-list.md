# RoboCup HSL 全球参赛队伍汇总档案

本文件完整归档 RoboCup 人形机器人足球联赛（Humanoid Soccer League, HSL）各组别（小型组 Small、中型组 Middle 与大型组 Large / AdultSize）的历史强队与参赛队伍信息，包含地区分布、所属学术机构、技术报告（TDP）、机械硬件规范（Robots）、系统软件报告（Software）及开源仓库索引。

数据源自官方竞赛委员会发布页面 [RoboCup HSL Qualified Teams](https://hsl.robocup.org/qualified-teams/) 以及历年公开技术报告。
