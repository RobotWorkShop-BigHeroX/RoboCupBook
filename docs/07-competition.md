# 7 第一次参赛：从报名到上场

参赛工作除了日常技术研发，还包括资质审核材料准备、设备装箱运输、现场检录合规性核验与标准化比赛流程。准备不充分可能直接导致无法上场参赛。

## 7.1 报名要准备什么

| 报名材料 | 核心内容与易漏点 | 建议提前筹备周期 |
| :--- | :--- | :--- |
| **TDP（技术描述文档）** | 机器人硬件设计、软件架构拓扑、感知定位与战术决策、测试实验数据。易漏点为本年度相较往届的技术迭代重点 | 赛前 2 个月 |
| **资格展示视频** | 规范展示机器人自主寻找目标球、带球绕桩、起脚射门与倒地起身全流程；使动作由自主控制算法驱动 | 赛前 1 个月 |
| **机器人参数核验表** | 身高、体重、足底面积与长宽比、各关节自由度分配与传感器型号明细清单 | 赛前 1 个月 |
| **参赛团队与院校资质** | 队员与指导教师名单、所属学术机构证明公函与联络渠道 | 随报名系统同步提交 |

资格视频应清晰呈现机器人的自主运行能力。拍摄时尽量采用全景机位，将机器人、场地标线与场外工作人员完整纳入画面，使动作自主性可被技术委员会明确核验。

## 7.3 抵达赛场后的检查

到达比赛场馆并布置好工位后，优先执行以下环境核验：

1. **核验赛场网络配置**：熟悉赛场指定网段划分、局域网访问限制与无线信道分配，确认裁判盒广播、机载系统与调试笔记本之间网络通路顺畅。
2. **标定场地视觉参数**：在真实比赛草皮上测试相机曝光参数、白平衡与检测置信度。室内场馆顶灯与自然采光与实验室存在差异，需现场测试确认是否需要重新微调参数。
3. **联调裁判盒状态切换**：连接现场官方 GameController，完整测试 INITIAL、READY、SET、PLAYING 及各种罚时状态跳转，验证机载逻辑响应是否正确。
4. **复核整机物理尺寸**：使用现场检录量具复测机器人直立高度、整机重量与足底投影尺寸，预留充足时间对超标部位进行打磨调整。

## 7.4 比赛日流程

| 时间节点 | 准备与检查任务 |
| :--- | :--- |
| **赛前 2 小时** | 动力电池充电就绪，检查机械紧固螺钉有无松脱，吊架下执行一次完整动作自检 |
| **赛前 1 小时** | 更换全新动力电池，复核机载配置中的队伍编号与球员编号，与当值裁判确认判罚细则 |
| **赛前 15 分钟** | 搬运机器人进场就位，执行最后一次无线网络连通性检查，进入 INITIAL 准备入场 |
| **比赛进行中** | 专人记录异常现象与发生时点；严禁在未留足测试验证时间的情况下现场临时改动核心代码 |
| **赛后 30 分钟** | 召集整场复盘，整理比赛日志与录像；现场仅针对明确缺陷进行单点修复并立即验证 |

## 7.5 现场调试与变更记录

- **一次只改动一处参数**：若同时调整多个参数，将无法定位起效或致错的具体变量。
- **每次变更均做书面记录**：详细记录改动发生时间、修改的代码位置或数值、调整前后的实际行为表现。
- **保持随时可回退状态**：修改代码前必须使用 Git 提交或备份，防止改动发散无法复原。

建议将“赛前 2 小时”设立为战队软件版本的冻结点。进入冻结期后，除已充分验证的参数微调外，严禁对软件整体架构或底层控制逻辑执行结构性改动。

## 7.6 赛后复盘模板

比赛结束后建议在当日完成结构化记录：

- **比赛关键失分点**：丢球、视觉误判、定位偏差、决策拥堵抑或电池欠压？
- **首次出现的异常现象**：该现象此前在实验室测试中是否出现过征兆？
- **单点优化方案**：若下一轮比赛仅允许修改一个参数或逻辑分支，应聚焦于何处？
- **下一场赛前验证指标**：下一轮上场前，必须在热身场地确切验证哪项动作？

复盘结论必须对应到可观测的具体现象、分析推导的原因与可执行的测试动作，为后续算法迭代提供可靠依据。
