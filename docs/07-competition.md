# 7 第一次参赛：从报名到上场

参赛工作除了日常技术研发，还涵盖资格材料审查、远途装箱运输、现场检录合规性裁决与紧凑的比赛日执行。之所以要将非技术流程制度化，是因为机器人足球是一项强工程依赖的实战联赛，硬件超重数公克、网口被防火墙阻断、甚至资格视频机位不合规，都会直接导致全队一年研发努力在检录阶段被一票否决。

## 7.1 报名资格材料准备

| 报名材料 | 核心内容要求 | 易漏点与审核风险 | 筹备周期 |
| :--- | :--- | :--- | :--- |
| **TDP（技术描述报告）** | 机器人机电设计参数、软件架构拓扑、感知定位与战术决策逻辑、实机测试实验数据 | 易漏写本赛季相较往年的技术迭代增量，报告通篇泛泛而谈极易被委员会评为低分 | 赛前 2 个月 |
| **资格展示视频** | 完整呈现机器人自主寻找目标球、带球避障绕桩、起脚射门与倒地自主起身的端到端流程 | 必须采用固定超广角全景机位，将机器人、场地标线与场外工作人员完整纳入画面，证明动作完全由自主算法驱动而非人工隐蔽遥控 | 赛前 1 个月 |
| **机器人参数核验表** | 直立身高、全备重量、足底接触面积与长宽比、各关节自由度分配与传感器型号明细 | 严禁填报预估值，必须以物理实测为准，一旦现场检录数据与报名单偏差过大将被责令限期整改 | 赛前 1 个月 |
| **团队与院校资质** | 参赛队员与指导教师名单、所属学术机构公函与联络渠道 | 核验随队人员保险与注册凭证 | 随报名系统提交 |

资格视频是技术委员会判定参赛准入的核心依据。之所以强调必须同框拍摄操作人员手脚，是因为评审专家首要排查的就是隐蔽遥控作弊；若画面频繁切换特写或镜头遮挡场外人员，极易招致作弊质疑并被直接驳回申请。

## 7.2 出发前：备赛打包清单

远途参赛面临物资匮乏与异地采购困难，装箱清单必须做到冗余完备：

| 类别 | 详细装箱明细 | 工程备用依据 |
| :--- | :--- | :--- |
| **机器人整机与动力** | 参赛整机（有条件必须配备同规格备用机）、各型号备用关节伺服电机、至少 4 组动力电池、平衡充电器与充电线 | 现场电机可能发生堵转烧损或齿轮断齿，备用机与备用电机是维持连续作战的底线依托 |
| **机械装配与测量** | 全套公制内六角扳手、各类规格紧固螺钉螺母、耐磨扎带、螺纹紧固胶、游标卡尺、水平尺与卷尺 | 剧烈对抗碰撞会导致紧固件震松，螺纹胶与卡尺是每日检修标定的必备工具 |
| **电气与网络耗材** | 屏蔽千兆网线、便携千兆交换机、大功率工业级防雷排插、现场规格电源转换插头、数字万用表、便携电烙铁与焊锡 | 现场工位往往仅提供单一电源插座，且场馆接地不良容易产生静电，屏蔽线与排插必不可少 |
| **计算与调试设备** | 现场调试笔记本电脑、备用固态硬盘、预装完整开发环境镜像的启动 U 盘 | 调试机一旦在赛场进水或系统崩溃，应急启动盘可在一小时内重建完整编译环境 |
| **场地与光学耗材** | 备用橡胶防滑脚垫、强力纤维胶带、无水乙醇与光学清洁布 | 赛场草皮表面存在粉尘污染镜头，脚垫磨损会导致打滑加剧，必须定期更换擦拭 |
| **合规与行政文件** | 纸质打印版规则手册（Rules.pdf）、纸质打印版 TDP、人员保险凭证与官方参赛邀请函 | 用于现场检录争议仲裁时逐字逐句出示官方依据 |

## 7.3 抵达赛场后的首日核验流程

到达比赛场馆并布置好工位后，必须按顺序执行以下环境核验：

1. **赛场网络拓扑核验**：接入赛场指定局域网，核对裁判盒广播网段与端口放行策略，确认机载系统与调试电脑之间 Ping 延迟稳定低于 5 毫秒且丢包率为零。
2. **现场草皮与光照标定**：在真实比赛草皮上测试相机曝光参数、白平衡与检测置信度。室内场馆顶灯色温与自然天光漫射与实验室存在显著偏差，必须就地微调相机曝光抑制高光反光。
3. **裁判盒全链路联调**：连接现场官方 GameController，完整测试 INITIAL、READY、SET、PLAYING 及各种罚时状态跳转，验证机载状态机是否准确响应。
4. **全备物理尺寸预检录**：借用现场检录工具，实测机器人直立高度、全备重量与足底投影面积。之所以要赛前自检，是因为若发现超重数百克，战队尚有充分时间打磨非承重结构件或更换轻量紧固螺栓。

## 7.4 比赛日标准化时间表

| 时间节点 | 准备与检查任务 | 纪律要求与风险规避 |
| :--- | :--- | :--- |
| **赛前 2 小时** | 动力电池充足就绪，检查机械紧固螺钉有无松脱，吊架下执行一次全动作功能回归测试 | **软件版本正式冻结**！严禁对算法架构执行任何结构性改动 |
| **赛前 1 小时** | 更换满电动力电池，复核机载程序中的队伍编号与球员编号，与当值裁判明确犯规裁量尺度 | 确认电池上下机械锁舌完全锁入卡槽 |
| **赛前 15 分钟** | 搬运机器人进场就位，执行最后一次无线网络连通性检查，进入 INITIAL 准备入场 | 安全监护手待命，手柄遥控手锁定阻尼状态 |
| **比赛进行中** | 专人详细记录异常现象、时间点与裁判判罚；严禁在缺乏完整回归测试时临时手写代码 | 记录现象优先于推测原因 |
| **赛后 30 分钟** | 召集全队整场复盘，备份导出 rosbag2 比赛数据包与行车日志；现场仅允许针对明确 Bug 执行单点参数微调并立即验证 | 严防改动发散引入次生故障 |

## 7.5 现场调试三大纪律

- **一次只改动一个参数**：若同时改动步态抬腿高度与视觉检测置信度，当出现踢球失准时，根本无法分辨是由于足底打滑还是视觉识别迟缓，由此导致排查方向彻底混乱。
- **每次变更均做书面记录**：详细记录改动发生时间、修改的代码位置、具体参数数值以及调整前后的物理表现差异。
- **保持随时可回退状态**：修改代码前必须使用 Git 在本地建立提交，一旦微调未达预期，能够一秒恢复至上一个稳定版本。

## 7.6 赛后复盘标准模板

比赛结束后建议在当日完成结构化记录：
- **比赛关键失分点**：丢球、视觉误判、定位混淆、决策死锁抑或电池欠压？
- **首次出现的异常物理现象**：该现象此前在实验室测试中是否出现过征兆？
- **单点优化方案**：若下一轮比赛仅允许修改一个参数或逻辑分支，应当聚焦于何处？
- **下一场赛前验证指标**：下一轮上场前，必须在热身场地确切验证哪项动作？

复盘结论必须对应到可观测的具体物理现象、分析推导的原因与可执行的测试动作，为后续算法迭代提供可靠依据。
