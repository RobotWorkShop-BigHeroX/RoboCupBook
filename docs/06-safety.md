# 6 实验室安全守则

人形机器人配置大扭矩高转速无刷关节电机，并具备高电压动力电源系统。即使机器人静止站立，伺服电机在使能状态下也具备突发施力能力。调试、搬运、测试与异常处置均需遵循既定规程。

## 6.1 上电之前：六项检查

每次合上高压动力电源前，必须逐项口头确认以下六点：

1. **吊机保护绳是否挂好**：吊装挂钩锁扣扣紧，保护钢丝绳/安全织带处于受力保护状态，预留 5 至 10 厘米下沉裕量。
2. **关节是否处于安全初始位**：根据平台要求调整各关节角度，严禁在关节扭曲或处于机械极限死点状态下直接通电。
3. **周围作业区域是否清空**：机器人一米活动半径内严禁站人，地面无拖拽线缆、螺钉工具或杂物。
4. **硬件急停开关是否在手边**：急停按钮放置于安全操作人员触手可及位置，一秒内能够拍下。
5. **遥控手是否明确指定就位**：指定专人握持遥控手柄，拇指置于阻尼保护按键上，测试全程专注盯紧机体姿态。
6. **三人测试小组是否全部到位**：推吊车、遥控手、安全监护三人缺一不可，严禁单人擅自通电测试。

任一检查项未满足前，严禁通电。

## 6.2 保护吊架的使用

保护吊架的核心作用是限制机器人失控跌倒时的下坠冲击，防止机械结构与电机减速器损毁，不能将其用于持续牵引机器人：

- 吊绳长度调节至机器人双足直立触地时绳索微松，保留 5 至 10 厘米垂直浮动空间。
- 吊挂受力点必须设置在机体躯干重心正上方的主结构吊环处，严禁挂在颈部头部或单侧肩关节。
- 机器人行走测试时，吊车操作人员应跟随机器人同步平移，避免主动施加拖拽力干扰步态。
- 整个上电机载调试期间，必须始终保持吊绳连接，严禁无防护状态自由踏步。

## 6.3 三人测试分工

| 岗位角色 | 代号 | 核心职责与操作位置 |
| :--- | :--- | :--- |
| **推吊车人员** | A | 双手平推吊架扶手，视线紧盯机体质心并同步移动，随时做好机体失衡时向上提拉的准备 |
| **遥控手人员** | B | 握持遥控手柄，拇指常置于阻尼按键，全程关注机器人动态，出现剧烈抖动立即触发阻尼 |
| **安全监护人员** | C | 位于硬件急停按钮与动力电源开关旁，监控线缆防缠绕与周围人员隔离，突发险情立即拍下急停 |

吊车员与遥控手在测试时注意力集中于机器人姿态，无法分心处理电源断开与人员疏散，因此需要独立的安全监护人专门负责电源控制与外围安全。

## 6.4 阻尼与急停的使用边界

| 维度 | 进阻尼（Damping Mode） | 拍急停（Emergency Stop） |
| :--- | :--- | :--- |
| **底层电气动作** | 控制器向电机驱动器下发阻尼使能指令，驱动器关闭主动力矩输出，利用电机反电动势提供柔性缓冲 | 通过继电器或物理接触器强行切断伺服电机的动力高压供电母线 |
| **防护作用** | 快速消除电机的主动驱动力，避免机器人大幅度甩动砸地，降低对机械关节的冲击 | 在主控程序崩溃、通信死锁或驱动器失控失联时彻底切断驱动动力 |
| **局限性** | 依赖机载通信与底层电机驱动器处于正常工作状态；无法应对短路或硬件级失控 | 切断供电后机体瞬间失去支撑力矩，将完全依赖保护吊架承受自重下坠 |
| **触发时机** | 步态发散、轻微抖动、行走方向偏离目标、规划异常 | 剧烈自激振荡、单腿猛烈甩动、冒烟起火、漏电或阻尼按键无响应 |

进阻尼是控制层面的保护手段，硬件急停是底层的断电防线。若出现阻尼失效、火花烟雾或对人身安全构成威胁的情况，立即拍下急停按钮。

## 6.5 三类常见危险状态

| 危险状态 | 典型特征与物理表现 | 危险原因分析 |
| :--- | :--- | :--- |
| **自激振荡** | 关节发生几十赫兹的高频剧烈振颤，幅度数秒内急剧扩大 | 控制闭环增益过高或相位超前导致正反馈发散，数秒内可击穿减速器齿轮或打穿驱动板 |
| **单腿支撑失控** | 一侧腿部突然猛烈蹬直或折叠收缩，机体严重倾侧 | 重心瞬间发生大范围偏移，几十公斤金属机体砸向地面会造成结构形变 |
| **线束干涉缠绕** | 机器人旋转时线缆拉紧受扯，关节转动受阻挂起 | 电机在堵转状态下持续输出最大堵转力矩，极易烧毁绕组或扯断信号线缆 |

观察到这几类危险状态，立即切换阻尼或拍下急停，严禁在电机通电使能状态下直接伸手扶正机身。

## 6.6 机器人跌倒后的处理

1. 确认周围人员撤离至安全距离，执行安全停机并彻底切断高压动力母线供电。严禁在关节仍处于使能输出状态下强行扶持机器人。
2. 拍照留存倒地姿态与现场环境，为后续排查控制算法故障或机械原因保留依据。
3. 检查受损情况：排查电机接插件有无松脱拉扯、结构件有无裂纹破损、减速器有无异响。
4. 确认动力完全断开后，手动轻转关节检查传动平顺度，若遇到卡阻切勿强行扳动。
5. 重新上电测试前，必须重新完成关节零位校核，并在吊架保护下由低速低风险动作开始验证。

## 6.7 开机与关机顺序

- **开机规范**：先合逻辑低压供电（工控机与传感器），等待操作系统加载与驱动节点自检完成；口头呼唱“注意，即将上动力电”提醒周边人员，确认安全后合上高压动力电源。
- **关机规范**：先通过软件向各关节发送去使能指令，机体安全平稳落锁后，断开高压动力总闸，最后关闭逻辑电源与工控机系统。
- **操作禁令**：严禁在关节处于异常扭曲受力、脚掌踩踏杂物线缆，或有人员肢体直接接触关节时合闸通电。

> [!CAUTION]
> **实验室工位安全准则**  
> **上电前**：吊机就位 · 关节归零 · 清场疏散 · 急停就手 · 遥控有人 · 三人到齐。  
> **异常时**：轻度失控立即进阻尼；剧烈抖动、通信失效或冒烟起火立即拍下急停；断电彻底后再行检修。  
> **原则**：始终保持人身安全在首位，先隔离高压动力电源，再检查设备与记录日志。
