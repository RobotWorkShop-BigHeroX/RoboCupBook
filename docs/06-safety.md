# 6 实验室安全守则

双足人形机器人集成了高转速、大减速比的伺服关节电机以及高电压、大容量动力锂电池。即使机体暂时处于原地站立静止状态，伺服驱动器在使能闭环下也具备毫秒级突发输出几十牛米峰值扭矩的能力。之所以必须建立严格的实验室安全操作规范，是因为双足机器人重达四十余公斤，一旦发生算法发散或硬件失控，不仅会瞬间造成高昂机械结构的永久损坏，极高的冲击动能还会对实验人员的人身安全构成致命威胁。

## 6.1 上电之前：六项检查

每次闭合高压动力电源开关前，安全测试小组必须逐项大声口头呼唱确认以下六项：

1. **吊机保护绳是否挂紧锁死**：吊装专用高强度挂钩锁扣必须完全闭合拧紧，保护钢丝绳或承重织带正处于垂直受力预紧状态，仅预留 5 至 10 厘米的极限下沉缓冲余量。
2. **关节是否处于标准初始姿态**：人工检查并拨动各个下肢关节角度，严禁在关节处于异常扭曲折叠或抵触机械极限死点的状态下合闸通电。
3. **周围作业包络区域是否清空**：机体周围一米物理回转半径内严禁任何人员逗留，地面绝不允许散落拖拽线缆、内六角扳手或螺钉杂物。
4. **硬件急停开关是否在手边就位**：物理急停按钮放置于安全监护人员手边一米范围内，使出现险情时一秒内能够单手拍下。
5. **遥控手是否明确指定并在岗**：指定专人双手握持罗技 2.4G 手柄，手指常置于 `左1` + `右1` + `Y` 阻尼组合键上，视线紧盯机体姿态，测试期间严禁交谈分神。
6. **三人测试小组是否全部到位**：推吊车、遥控手、安全监护三人缺一不可，严禁单人私自上电测试。

任一检查项存在疑问或未落实前，严禁闭合动力电源。

## 6.2 保护吊架的使用规范与物理禁令

保护吊架的核心职责是限制机器人失衡跌倒时的瞬态坠落行程，借以保护精密减速器齿轮与碳纤维承重骨骼不受冲击毁损，绝对不能将其作为外部吊拉行走的支撑辅具：

- 吊绳长度调节至机器人双足直立触地时绳索微松，保留 5 至 10 厘米垂直位移余量。吊绳调得过紧会人为分担足底法向载荷，导致地面反作用力解算失真，彻底破坏步态稳定性；吊绳放得过长则会在失衡跌倒时失去悬挂拦截保护。
- 吊挂受力点必须设置在机体躯干重心正上方的合金主吊环处，严禁挂在颈部头部或单侧肩关节，防止跌落拉扯时导致躯干倾翻甚至颈部骨架断裂。
- 机器人行走测试时，吊架操作人员必须双手稳扶吊车并跟随机体同步平移，避免主动施加拖拽外力干扰足底接触。
- **悬吊状态强行运行禁令**：严禁在机器人处于悬吊腾空状态下强行运行行走或踢球运动模型。运动控制算法在解算时严格依赖足底触地开关检测地面反作用力，若在腾空状态下激活模型，算法因检测不到预期的触地载荷判定支撑相缺失，控制器将不断加大摆动幅度并猛烈蹬腿，迫使关节以极限角速度疯狂空转甩动，极易击打周边人员或扯断机身线缆。

## 6.3 三人测试小组的职责分工

| 岗位角色 | 岗位代号 | 核心职责与操作位置 |
| :--- | :--- | :--- |
| **推吊车人员** | A 岗 | 双手平推吊架扶手，视线紧盯机体质心并同步平移移动，随时做好机体失衡时向上提拉吊架的准备 |
| **遥控手人员** | B 岗 | 双手握持罗技手柄，手指常置于 `左1` + `右1` + `Y` 键，全程聚焦观察机器人动态，出现剧烈抖动立即同时按下触发阻尼 |
| **安全监护人员** | C 岗 | 独立守在硬件急停按钮与动力电源总闸旁，监控线缆防缠绕与周围人员隔离，突发极端险情立即拍下急停 |

之所以必须严格配置独立安全监护人，是因为吊车员与遥控手在测试时注意力全部被机器人动态姿态所占用，根本无法在突发状态下分心处理电源断开与人员疏散。

## 6.4 阻尼与急停的使用边界与权衡取舍

| 处置方式 | 进阻尼（Damping Mode） | 拍急停（Emergency Stop） |
| :--- | :--- | :--- |
| **底层电气动作** | 控制器向电机驱动器下发阻尼使能指令，驱动器关闭主动力矩输出，利用电机反电动势提供柔性缓冲阻尼 | 通过大功率接触器强行物理硬切断伺服电机的动力高压供电母线 |
| **物理后果** | 电机平滑吸纳残余动能并平稳停止，机体在重力作用下缓慢下沉，被保护吊架平稳接住 | 机体所有关节力矩瞬间归零，机身按自由落体猛烈砸地，造成减速器断齿或外壳砸碎 |
| **依赖条件** | 依赖机载操作系统与底层 CAN/EtherCAT 通信总线仍处于正常响应状态 | 纯硬件电路硬切断，即使机载操作系统彻底崩溃死锁依然可靠生效 |
| **触发时机** | 步态发散、轻微抖动、行走方向偏离目标、规划异常 | 剧烈自激振荡、单腿疯狂甩动、冒烟起火、漏电或手柄阻尼按键完全无响应 |

之所以在日常调试中严厉禁止随意拍下急停，是因为 T4 平台全重四十余公斤，拍下急停直接下电会导致沉重机体瞬间砸落；除非面临起火、冒烟、卷入人员肢体等不可逆的危险，日常失调必须由遥控手通过 `左1` + `右1` + `Y` 组合键平稳切入阻尼。

## 6.5 三类常见危险状态的物理机理

| 危险状态 | 典型物理表现 | 危险机理与破坏后果 |
| :--- | :--- | :--- |
| **自激振荡** | 关节发生几十赫兹的高频剧烈振颤，伴随刺耳蜂鸣，振幅数秒内急剧发散 | 控制器闭环增益过高或相位超前导致正反馈发散，数秒内即可击穿减速器行星齿轮或打穿驱动板 MOS 管 |
| **单腿支撑失控** | 一侧腿部突然猛烈蹬直或折叠收缩，机体严重向一侧倾侧 | 质心瞬间脱出足底支撑多边形，几十公斤金属机体猛烈砸向地面造成骨骼形变 |
| **线束干涉缠绕** | 机器人旋转时线缆拉紧受扯，关节转动受阻卡死 | 电机在堵转状态下持续输出最大堵转力矩，极易在几秒内烧毁定子绕组或扯断传感器总线 |

一旦在视线中捕捉到这几类危险征兆，遥控手必须在一秒内触发阻尼切断主动力矩输出，绝对禁止在电机通电使能状态下盲目伸手扶正机身。

## 6.6 机器人跌倒后的标准化处置流程

1. **彻底隔离电源**：确认机身完全静止后，安全监护人员立即切断高压动力母线供电总闸，严禁在关节仍处于通电使能状态下上前触碰扶持。
2. **留存事故现场**：对跌倒姿态、地面摩擦划痕与周边环境进行多角度拍照留档，为后续复现控制逻辑缺陷或机械故障保留真实证据。
3. **逐项物理排查**：检查电机航插接插件有无拉脱或针脚松动，排查碳纤维骨架有无肉眼可见的受力裂纹，检查减速器外壳有无破损漏油。
4. **手动轻转校验阻力**：确认动力完全切断后，用手轻转各个关节，感受传动平顺度，若遇到明显卡阻或异响，严禁强行扳动，必须拆机检修。
5. **重新标定零位**：跌落撞击通常会造成关节编码器读数或机械销位微小位移，再次通电前必须重新执行关节零位标定，并在保护吊架约束下从极低速度动作开始递进验证。

## 6.7 开机与关机顺序

- **开机规范**：必须先开启低压逻辑供电电源，等待 Ubuntu 操作系统启动、驱动节点与传感器自检完成；随后口头大声呼唱“注意，即将上动力电”提醒周边人员避让，确认无人触碰机体后，合上高压动力电源开关。
- **关机规范**：先通过软件向各关节发送去使能指令，等待机体平稳进入阻尼挂架状态后，断开高压动力电源总闸，最后关闭低压逻辑电源与工控机系统。
- **安全操作禁令**：严禁在关节处于异常扭曲受力、脚掌踩踏杂物线缆，或有人员肢体直接接触关节时合闸通电。

> [!CAUTION]
> **实验室工位安全准则**  
> **上电前**：吊机就位 · 关节归零 · 清场疏散 · 急停就手 · 遥控有人 · 三人到齐。  
> **异常时**：轻度失控立即进阻尼；剧烈抖动、通信失效或冒烟起火立即拍下急停；断电彻底后再行检修。  
> **原则**：始终保持人身安全在首位，先隔离高压动力电源，再检查设备与记录日志。
