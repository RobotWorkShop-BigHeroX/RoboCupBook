\section{消息渠道}

规则修订、赛程调整和报名通知可能分散在多个官方渠道。建议将以下入口加入队内资料库，并明确由谁定期检查。

\subsection{优先关注的两个渠道}

\begin{enumerate}[leftmargin=*]
    \item \textbf{官方邮件列表。} 技术委员会和组委会可能通过邮件发布规则修订、资格通知和重要裁决。订阅后仍应留意当届官网的补充通知。\official
    \begin{itemize}
        \item 订阅地址：\url{https://lists.robocup.org/mm/lists/robocup-humanoid.lists.robocup.org/}
        \item 建议使用队内公共邮箱订阅，便于成员交接，避免个人离队后通知无人接收。
    \end{itemize}
    \item \textbf{官方 Discord。} 这里可用于了解赛事讨论、现场网络问题和规则解释等信息。回复速度取决于具体问题与在线人员情况。\official
    \begin{itemize}
        \item 加入链接：\url{https://discord.gg/67qGN8ycwz}
        \item 提问前先搜索历史消息，并附上相关日志、环境信息和复现步骤，以便其他队伍定位问题。
    \end{itemize}
\end{enumerate}

\subsection{队内信息维护流程}

订阅本身不能保证重要通知得到处理。队内应明确维护责任，并安排固定的检查频率：

\begin{itemize}[leftmargin=*]
    \item 一人盯邮件列表，每周扫一次，规则相关的转进队群。
    \item 一人盯 Discord 的规则与赛事频道，其余频道不用看。
    \item 规则仓库每两周对一次 \texttt{git log}，有改动就记进变更表。
\end{itemize}

\noindent 每个赛季结束后，应保存当届规则版本及对应的 commit 哈希或 release 标签。这样在需要追溯条款变化时，可以定位到具体版本。\advice
