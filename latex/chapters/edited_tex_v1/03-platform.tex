\subsubsection{远程登录与网络连接}

\begin{enumerate}[leftmargin=*]
    \item \textbf{物理连接：} 使用标准 RJ45 网线连接机身背部调试网口与外部开发笔记本电脑。之所以采用有线直连，是因为比赛场馆无线信道极度拥挤且存在同频干扰，迫使底层固件调试、程序分发与系统维护必须依托高抗扰的物理双绞线。
    \item \textbf{IP 地址配置：}
    \begin{itemize}

    \item \textbf{远程登录凭证：}
    \begin{itemize}

    \end{itemize}
\end{enumerate}

\subsubsection{开机与遥控手柄操作}

\begin{enumerate}[leftmargin=*]
    \item \textbf{开机流程与初始状态：}
    \begin{itemize}
        \item 开机前首先检查背部红色急停开关处于顺时针旋转松开弹起状态；核验动力电池上、下两处机械锁舌完全卡入锁槽，防止机体走动时电池脱落造成瞬时断电。
        \item 按下机身背部中间电源开关，等待机载工控机与伺服板卡完成自检，启动耗时约为 30 至 60 秒。
        \item 启动完毕后，系统处于初始准备状态，此时全身关节呈现零阻力特性，可以用手自由拨动关节摆出指定初始姿势。必须在保护吊架拉紧状态下进行此操作，防止机体由于关节无力矩支撑就地软瘫坠地。
    \end{itemize}
    \item \textbf{手柄组合键定义（罗技无线手柄）：}
    \begin{itemize}
        \item \textbf{准备就绪（Ready）：} 同时按下 \texttt{左1}（LB） + \texttt{执行按键 A}，下肢各个关节电机开始受电，缓慢旋转至标准直立零位姿态。
        \item \textbf{开始运行模型：} 同时按下 \texttt{左1}（LB） + \texttt{执行按键 B}，开始执行当前加载的行走或踢球运动模型。
        \item \textbf{紧急切换阻尼：} 同时按下 \texttt{左1} + \texttt{右1} + \texttt{执行按键 Y}，机器人各个关节瞬间切入阻尼耗能状态，迅速吸收残余动能并平稳停止。
        \item \textbf{阻尼后复位：} 同时按下 \texttt{左1} + \texttt{右1} + \texttt{执行按键 X}，等待 3 秒后系统恢复初始零阻力状态。
        \item \textbf{移动控制（行走模型激活状态下）：} 摇杆回中时机体保持原地踏步或踏步直立；左拨杆负责推拉控制机体前后左右平移速度，右拨杆左右拨动负责控制机体转向角速度。
        \item \textbf{手柄休眠唤醒：} 手柄在停止操作一段时间后会自动切入低功耗休眠，点按一次 \texttt{左1} 或 \texttt{右1} 按键即可重新建立无线配对。
    \end{itemize}
\end{enumerate}

\begin{noticebox}[关节零位校准]
关节绝对零位由高精度光电编码器读数与机械标定销位共同确定。一旦经历猛烈冲撞跌落、更换伺服减速器或发现零位漂移，必须依照厂家标定治具重新写入绝对零位偏置，否则运动学正反解算将全盘失准。
\end{noticebox}

\subsection{IMU 与姿态估计}

机载 IMU（惯性测量单元）是维持双足机器人动态平衡的神经中枢，持续输出高频运动学物理量：三轴角速度测量机体在三维空间中旋转的动态角速率，用于快速检测失衡翻转趋势；三轴加速度测量重力加速度在机体坐标系下的分量以及外力碰撞产生的瞬态冲击；芯片内部硬件互补滤波解算出横滚角（Roll）、俯仰角（Pitch）与偏航角（Yaw）。

在运控系统中，IMU 数据直接参与平衡控制器的反馈回路。当横滚角或俯仰角超出动态稳定包络（如机体倾斜超过 35 度）时，安全保护逻辑将立即切断行走模型并触发阻尼或倒地保护动作。

\subsection{足式里程计与误差累积机理}

人形机器人缺少轮式车辆连续滚动的物理车轮，其位移推算完全依赖非连续足底接触的正运动学推导：通过足底触地开关检测支撑相，利用关节编码器读数正向推算支撑足底相对机体质心的位置，再假设足底与地面无相对滑动，逆向推导出机体相对地面的位移增量。

足式里程计之所以必然产生累积漂移，归因于以下客观物理制约：

足式里程计能够提供高采样率、低延迟的短时运动增量，但无法独立消除长期漂移；相机视觉观测采样率较低且存在几何对称混淆，但具备绝对位置无累积误差的特性。两者的深度融合是实现稳定定位的前提。

\subsubsection{上电与接线操作规程}

\begin{enumerate}[leftmargin=*]
    \item \textbf{坚持固定的上电顺序：} 必须先开启低压逻辑电源，等待工控机系统加载完毕、通信总线初始化成功后，再闭合高压动力电源。反向操作会在逻辑控制引脚未建立稳定参考电平的情况下突然施加高压，极易导致伺服驱动器瞬态逻辑错乱。
    \item \textbf{严防动力锂电池过放：} 锂电池单体电压绝对禁止跌破安全截止阈值。一旦机载报警蜂鸣器响起或电压低于设定红线，必须立即下电充电；长期闲置的电池应维持在半电荷储存状态。
    \item \textbf{急停按钮的物理后果认知：} 必须深刻认识到急停按钮是硬件切断动力，切断后机器人将瞬间失去任何支撑力矩并直接按自由落体撞地砸损。常规测试出现失控苗头时，应当优先使用遥控器按下组合键切入阻尼状态，仅在遭遇线路冒烟、明火或人员安全受到威胁时才允许拍下急停。
    \item \textbf{更换器件后的绝缘核验：} 在更换电机、传感器或重新走线后，必须先用万用表排查电源对地是否短路，确认信号线无错位后方可接入电池上电。
\end{enumerate}

\begin{verbatim}
git submodule update --init --recursive
\end{verbatim}
任何涉及底层通信协议修改、逆运动学连杆长度校验或电气接口排查的任务，均应直接查阅对应硬件技术手册中的标准工程图纸。\practice
